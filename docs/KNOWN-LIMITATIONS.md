# 已知边界与未验证项（诚实清单）

## 能力边界

1. **只防增量**。content-firewall 处理的是"工具结果进入上下文"这一时刻；你直接粘贴的文本、
   模型自己生成的内容**不经过它**。回溯清洗只有 `history-scrub`（显式人工操作）。
2. **遮罩不是理解**。它是词表 + 结构规则的工程近似：同义改写、隐喻、外文混排都可能漏网；
   反过来，正常文本也可能被遮（可接受——这只影响模型看到的细节，不影响正确性）。
3. **残余层的取舍**（v2.2 起默认开）：结构豁免行（URL/版本行/选择器行）中若含敏感词，
   现在会被一并遮掉。防拒答优先于细节保留；`CONTENT_FIREWALL_RESIDUAL=off` 可退回旧行为
   （旧行为等于"该行原样发给网关"——可能直接触发拒答）。
4. **网关是概率型的**。本方案提高的是"存活率"，不是"保证通过"；熔断（默认 30 分钟内 3 次）
   是设计内的终点，之后请走换模型/新会话/深度清洗。

## 未验证 / 弱验证项

1. **"空闲死态被唤醒"未单独做活体实验**（截至发布）：已证明的是"注入能到达正在进行的回合"
   与"注入通道在 remote-worker 形态下可用"；"会话完全空闲（拒答后无人操作）时注入会自主开新
   回合"依赖同一条消息队列路径，有跨会话推送先例，但未在本项目里单独录像。首次真实拒答即
   端到端验收；若该环失效，行为回落到"现状无损害"（不重试、不静默失败）。
2. **对真实锁死会话的完整恢复演练**：清洗工具与加载链路已分别实证（见 RECOVERY-PLAYBOOK），
   但"一个真实的、被锁死的业务会话被完整救活"的案例尚未发生（需等真实事件）。
3. **平台契约漂移**：钩子字段（`asyncRewake`、`updatedToolOutput`、事件语义）来自对 Qoder
   0.4.2 的解包与实测；上游更新后可能变化。升级客户端后建议重跑 `tests/`。

## 合规提醒（重要）

- 仅在你自己的账号、你自己的合法内容上使用。
- 遵守模型服务商的服务条款与当地法律；不要用于违法内容。
- 这类工具**可能**被平台解读为规避审核，并带来账号风险——使用前请自行评估。
- 本项目不提供内容生成能力，也不包含任何越狱提示词；它只做遮罩、重试、通知与清洗。
