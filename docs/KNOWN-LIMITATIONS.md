# 已知边界与未验证项（诚实清单）

## 能力边界

1. **只防增量**。content-firewall 处理的是"工具结果进入上下文"这一时刻；你直接粘贴的文本、
   模型自己生成的内容**不经过它**。回溯清洗只有 `history-scrub`（显式人工操作）。
2. **遮罩不是理解**。它是词表 + 结构规则的工程近似：同义改写、隐喻、外文混排都可能漏网；
   反过来，正常文本也可能被遮（可接受——这只影响模型看到的细节，不影响正确性）。
3. **残余层的取舍**（v2.2 起默认开）：结构豁免行（URL/版本行/选择器行）中若含敏感词，
   现在会被一并遮掉。防拒答优先于细节保留；`CONTENT_FIREWALL_RESIDUAL=off` 可退回旧行为
   （旧行为等于"该行原样发给网关"——可能直接触发拒答）。
4. **网关是概率型的**。本方案提高的是"存活率"，不是"保证通过"；熔断（默认 30 分钟内 3 次）
   是设计内的终点，之后请走换模型/新会话/深度清洗。
5. **模型门依赖一个未公开字段**（2026-09-25 复核）：官方 `PostToolUse` 字段清单里**没有**
   `model`（文档只在 SessionStart 一节列了它），但运行时实测 payload 里**有**——本机 CLI
   1.1.62 抓包为 `"model":"str:14"`（值 `DeepSeek-Flash`），探针留档 `event-probe2.jsonl`。
   取舍：字段在场且不匹配 → 原样放行（这是模型门的本意）；字段**缺失** → 同样放行，但写一行
   `rule=no_model_skip` 审计，把"静默失效"变成可观测。**与 refusal-recovery 的不对称是有意的**：
   遮罩会改写用户可见数据，未知模型时宁可不碰；恢复只在失败后动作，未知模型也值得救。
6. **计数按全文做**（2026-09-25 起）。此前只在结果的前 512 KiB 内计数，超长结果的尾部命中会
   被整条放行；现改为全文计数，实测成本约 5 ms/MB（8 MB 全净文本端到端 ~0.5 s，含进程启动），
   相对 10 s 钩子超时可忽略。
7. **巡检是启发式的，且强依赖 transcript 布局**（`refusal-watchdog.mjs`）：它读的是客户端
   自己写的会话 JSONL（每行一个 JSON 事件、助手条目的 `model` 字段、时间戳字段名 `timestamp`）。
   客户端改格式 ⇒ 巡检静默失灵（**它不改任何东西，所以失灵无害，只是不再报警**）。它是
   "事后发现"手段，不是防线：真正的防线是遮罩与熔断。收件箱语义=**读后即删、只报一次**
   （`prompt-gate` 呈报后删除 pending 文件），所以错过那条 systemMessage 就等于错过通知。

## 未验证 / 弱验证项

1. **"空闲死态被唤醒"未单独做活体实验**（截至发布）：已证明的是"注入能到达正在进行的回合"
   与"注入通道在 remote-worker 形态下可用"；"会话完全空闲（拒答后无人操作）时注入会自主开新
   回合"依赖同一条消息队列路径，有跨会话推送先例，但未在本项目里单独录像。首次真实拒答即
   端到端验收；若该环失效，行为回落到"现状无损害"（不重试、不静默失败）。
2. **对真实锁死会话的完整恢复演练**：清洗工具与加载链路已分别实证（见 RECOVERY-PLAYBOOK），
   但"一个真实的、被锁死的业务会话被完整救活"的案例尚未发生（需等真实事件）。
3. **平台契约漂移**：钩子字段（`asyncRewake`、`updatedToolOutput`、事件语义）来自对 Qoder
   0.4.2/CLI 1.1.62 的解包与实测；上游更新后可能变化。升级客户端后建议重跑 `tests/`，并
   `tail` 审计文件：若出现 `rule=no_model_skip`，说明模型门赖以工作的字段消失了（见能力边界 5）。
4. **巡检只在本机验证过**（Qoder 的 transcript 布局）。换客户端后请先用
   `node hooks/refusal-watchdog.mjs --json --root <该客户端的会话目录>` 手工跑一次，确认真能
   扫到拒绝样本再挂进流程——否则你只是在定期扫描 0 个文件。

## 合规提醒（重要）

- 仅在你自己的账号、你自己的合法内容上使用。
- 遵守模型服务商的服务条款与当地法律；不要用于违法内容。
- 这类工具**可能**被平台解读为规避审核，并带来账号风险——使用前请自行评估。
- 本项目不提供内容生成能力，也不包含任何越狱提示词；它只做遮罩、重试、通知与清洗。
